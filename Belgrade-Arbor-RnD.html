Executive Summary

Belgrade Arbor is a premium real-estate presentation site for a residential & business complex in New Belgrade. It positions the property as an experience rather than a listing.

Design Philosophy: Editorial luxury meets architectural precision. The site treats property marketing like a high-end editorial magazine — every scroll is choreographed, every transition is intentional. Content is revealed, never simply shown. The visual language draws from nature (arbor = trees), earth tones, and botanical elegance.

Typography Rules:

Responsive Strategy

Mobile-first with Tailwind's max-* breakpoint system. Key sections have entirely separate desktop/mobile markup.

BreakpointClassStrategy
< 640pxmax-sm:Phone: stacked layouts, reduced typography, simplified animations
< 768pxmax-md:Tablet small: mobile menu, sliders → stacked, separate section markup
< 1024pxmax-lg:Tablet: reduced gaps, smaller hero text, repositioned elements
< 1280pxmax-xl:Small desktop: hero text 7.5rem instead of 10.5vw
< 1536pxmax-2xl:Large desktop: minor adjustments
Key responsive patterns:
• Duplicate markup: Sections 2, 9 have entirely separate desktop (max-md:hidden) and mobile (hidden max-md:block) versions
• Hero text scaling: H1 text-[10.5vw] → text-[17vw] on mobile
• Slider → stack: All Keen Sliders show all slides on mobile (max-md:opacity-100)
• Sticky → static: Scroll-pinned sections become normal flow on mobile
• Paragraph headings: 57px → 43px on mobile (mobile-heading1/2 classes)

Character-by-Character Text Reveal

Hero headings split into 1,185 individual <div> elements, each animated with staggered translate + opacity.

/* Each character wrapped in <div style="display:inline-block"> */ /* Initial: */ opacity: 0; transform: translate(0, 100%); /* Final: */ opacity: 1; transform: translate(0, 0); /* Stagger: ~25ms per char · Duration: 600ms per char */
Animation 05
Scroll Parallax

Images scroll at 0.3–0.5x page speed. Achieved by animating the top property on oversized absolute images.

/* Container clips the oversized image */ .parallax-container { overflow: hidden; position: relative; } .parallax-img { position: absolute; width: 100%; height: calc(100% + 20rem); /* 320px extra */ top: 0; /* JS updates on scroll via rAF */ } /* 5 parallax instances: intro, retail, amenities, installment, residence-gallery */
Animation 06
Zoom-Out Reveal

Images start at scale(1.1) and ease to scale(1.0) during clip-path reveal — cinematic "pull-back".

No GSAP. Despite the complexity, Belgrade Arbor uses NO external animation libraries. Everything is built with:
• Native CSS clip-path transitions (primary reveal)
• Inline style transforms via custom JS (translate, scale, opacity)
• IntersectionObserver for scroll triggers
• requestAnimationFrame for parallax
• Tailwind CSS transition utilities for micro-interactions
• Keen Slider library for carousels only

Easing: cubic-bezier(0.16, 1, 0.3, 1) — fast start, gentle settle (all JS animations)
Easing: ease-in-out — Tailwind utility transitions
