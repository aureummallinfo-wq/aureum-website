Loading Screen

A branded preloader that sets the pace — the first signal that this is an experience, not a webpage.

☙
0%
Duration
3–5 seconds (asset-dependent)
Elements
Centered tree logo + progress bar + serif percentage counter
Background
#FDFBEF (Vanilla) — same as page bg for seamless transition
Exit
Entire loader fades out with opacity: 0 over 600ms, then display: none
Easing
cubic-bezier(0.4, 0, 0.2, 1) — smooth deceleration
/* Loading bar animates width from 0% → 100% */ .loader-bar { width: 0%; transition: width 3s cubic-bezier(0.4, 0, 0.2, 1); } /* Percentage counter updates via JS requestAnimationFrame */ /* On complete: entire loader wrapper fades out */ .loader-exit { opacity: 0; transition: opacity 600ms ease; pointer-events: none; }
02

Blueprint-to-Render Reveal

The signature hero animation — an architectural line drawing morphs into a photorealistic 3D render. Three layered screens cross-fade sequentially.

Hero — Signature Animation
Technique
3 absolutely-positioned full-screen layers (.screen1, .screen2, .screen3) cross-fading via opacity
Container
.morphs.absolute.inset-0 — parent of all 3 screens inside .intro-parallax
Trigger
Fires after loading bar reaches 100%, chained with pointer-events: none on completed screens
Duration
~3s total (1–1.5s per screen transition)
/* 3 layered screens stacked absolutely */ .morphs { position: absolute; inset: 0; } .screen1, .screen2, .screen3 { position: absolute; inset: 0; width: 100%; height: 100%; } /* JS tweens opacity sequentially: screen1 (blueprint): 1 → 0 at t=0–1.5s screen2 (partial): 0 → 1 → 0 at t=0.5–2.5s screen3 (render): 0 → 1 at t=1.5–3s Each completed screen gets pointer-events: none */
03

Clip-Path Section Reveal

The primary scroll animation — entire sections revealed by animating CSS clip-path: inset(). Content wipes in from top, images wipe in from bottom.

Core Technique — Used Everywhere
CONTENT (top→down)
A New Chapter
in Living
IMAGE (bottom→up)
Content reveal
clip-path: inset(100% 0% 0%) → inset(0% 0% 0%) — wipes downward
Image reveal
clip-path: inset(0% 0% 100%) → inset(0% 0% 0%) — wipes upward
Section wipe
clip-path: inset(0% 100% 0% 0%) → inset(0%) — wipes from left
Duration
800ms–1200ms
Easing
cubic-bezier(0.16, 1, 0.3, 1) — fast start, gentle settle
Stagger
Image delayed ~200ms after content
Trigger
IntersectionObserver on .trigger elements at ~15% threshold
/* Initial state — hidden */ .reveal-content { clip-path: inset(100% 0% 0%); /* hidden from top */ } .reveal-image { clip-path: inset(0% 0% 100%); /* hidden from bottom */ } .trigger { clip-path: inset(0% 100% 0% 0%); /* hidden from right */ } /* JS tweens clip-path to inset(0%) on scroll using IntersectionObserver + requestAnimationFrame Easing: cubic-bezier(0.16, 1, 0.3, 1) Duration: 800–1200ms */ /* Revealed state */ .reveal-content.visible, .reveal-image.visible { clip-path: inset(0%); }

Character-by-Character Text Reveal

Hero headings split into individual characters, each wrapped in its own <div>, then animated with staggered translate + opacity.

Typography Animation
Total chars
1,185 individually animated <div> elements across the page
Initial state
opacity: 0; transform: translate(0, 100%) — chars start below baseline
Final state
opacity: 1; transform: translate(0, 0)
Stagger
~20–30ms between each character
Duration
~600ms per character
Hero class
.heading.huge — 10.5vw on desktop, 17vw on mobile
Wrapper style
position: relative; display: inline-block;
/* Each character is wrapped in an individual div */ .char-wrapper { position: relative; display: inline-block; translate: none; rotate: none; scale: none; } /* Initial: hidden below baseline */ .char-wrapper { opacity: 0; transform: translate(0px, 100%); } /* Animated to: visible at origin */ .char-wrapper.visible { opacity: 1; transform: translate(0px, 0px); } /* JS stagger: forEach(char, i) => delay = i * 25ms Applied via inline style transform tween */
05

Scroll Parallax

Images scroll at a slower rate than content, creating cinematic depth. Achieved by animating the top property on oversized images.

Technique
Image is 20rem taller than container, position: absolute, top animated via JS on scroll
Container
overflow: hidden clips the oversized image — viewer only sees container-height portion
Speed ratio
~0.3–0.5x page scroll speed (image moves slower than page)
Classes
intro-parallax, retail-spaces-parallax, amenities-parallaxWrap, installment-parallax, residence-gallery-parallaxWrap
Gallery variant
-translate-y-[10%] scale-120 — starts shifted up and zoomed, settles on scroll
06

Zoom-Out Reveal

Images start slightly zoomed in (scale 1.1) and ease to 1.0 during the clip-path reveal, creating a cinematic "pull-back" effect.

Image
Class
.reveal-image-zoom
Initial scale
transform: scale(1.1, 1.1)
Final scale
transform: scale(1.0, 1.0)
Combined with
Clip-path reveal — zoom happens during the unmasking
Duration
~1.8s (longer than clip-path for smooth deceleration)
/* Outer: clip-path reveals the image */ .reveal-image { clip-path: inset(0% 0% 100%); /* hidden */ } /* Inner: slightly zoomed, scales down during reveal */ .reveal-image-zoom { transform: scale(1.1, 1.1); } /* On trigger — both animate together */ .reveal-image.visible { clip-path: inset(0%); /* 1.2s */ } .reveal-image-zoom.visible { transform: scale(1, 1); /* 1.8s — lingers */ }

Carousel (Keen Slider)

6 slider instances across the page, all using opacity fade transitions instead of the typical horizontal slide.

Library
Keen Slider — lightweight touch slider
Instances
6 sliders (residences, location details, apartment photos, etc.)
Transition type
Opacity fade — NOT horizontal slide. Active: opacity-100, inactive: opacity-0
Duration
duration-700 (700ms) via Tailwind class
Navigation
Circular outlined arrows (44px, 1px border), gold on hover
Mobile
All slides visible stacked (max-md:opacity-100)
/* Keen Slider with opacity fade transition */ .keen-slider__slide { transition: opacity 700ms; } .keen-slider__slide.active { opacity: 1; } .keen-slider__slide:not(.active) { opacity: 0; } /* Mobile: all visible, stacked vertically */ @media (max-width: 768px) { .keen-slider__slide { opacity: 1 !important; } }

Sticky Elements
No GSAP. Despite the complexity, Belgrade Arbor does NOT use GSAP, Framer Motion, or Locomotive Scroll. All animations are built with:
• Native CSS clip-path transitions (the primary reveal technique)
• Inline style transforms via custom JS (translate, scale, opacity)
• IntersectionObserver for scroll triggers
• requestAnimationFrame for smooth scroll-linked parallax
• Tailwind CSS utility transitions for micro-interactions
• Keen Slider library for carousels only
